# ARIA MASTER ROADMAP V3 — 2026-09-06

## Purpose
Single canonical roadmap for ARIA's evolution from the current autonomous runtime into a durable cognitive operating system and multi-agent platform.

## Certification states
- DESIGN: architecture/specification exists, not enough implementation evidence.
- IMPLEMENTED: code/contracts/tests exist, not necessarily live.
- INTEGRATED: connected to canonical runtime/control plane.
- LIVE: exercised against a real external system/runtime.
- CERTIFIED: live evidence + tests + no-regression audit + documentation.
- HUMAN_GATE: requires external owner/security/configuration action after autonomous alternatives are exhausted.

- Block 1 — Cognitive Loop v2: CERTIFIED.

## Global definition of done
No block is certified merely because source files or unit tests exist. Certification requires the applicable implementation, canonical integration, live evidence, security/governance checks, regression evidence, and ChatBending documentation. Human Gates are valid only for external authority/configuration actions that ARIA cannot perform or bypass safely after exhausting autonomous alternatives.
