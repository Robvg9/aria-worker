# BLOCK 11/11 — ARIA META-REASONING

Status: SPECIFICATION

Objective: give ARIA an explicit metacognitive control layer that evaluates confidence, evidence sufficiency, strategy history, skill/agent fit, investigation need, experimentation need, and human-gate requirements before autonomous action.

Missions:
11.1 Meta-Reasoning Contract
11.2 Evidence Sufficiency
11.3 Confidence / Uncertainty Gate
11.4 Failure-Strategy Detection
11.5 Better Skill / Agent Detection
11.6 Research / Investigation Decision
11.7 Experiment-or-Abstain Decision
11.8 Human Gate Detection
11.9 Router Meta-Reasoning Overlay

Safety boundaries:
- Meta-reasoning is deterministic, secret-free and control-plane only.
- It does not execute tools, models, agents, experiments or approvals.
- Security 2.0 remains the authorization authority.
- Resource / Cost Intelligence remains the economic authority.
- Human gates cannot be bypassed.
- Unknown evidence is never converted into positive evidence.
- Abstention is a valid successful control outcome.

This scope becomes certified only after implementation, regression and LIVE evidence are complete.
