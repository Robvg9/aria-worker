# OmniRoute Phase 14 — Comparative Evaluation Contract v1.0.0

## Scope
Compare the ARIA default route, governed OmniRoute routing and OmniRoute→local Qwen as architectural paths.

## Evidence boundary
Static comparison covers authority, evidence, fallback, security and local-model capability.
Runtime latency, response quality, cost and provider success require LIVE measurements and are therefore explicitly pending.

## Gate
Reproducible comparison with no fabricated runtime metrics.

## Current conclusion
OmniRoute→local Qwen is the most relevant architectural path for the free/local strategy, but no promotion decision is made until LIVE E2E.
